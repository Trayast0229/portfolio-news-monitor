# Portfolio News Monitor API

The backend of [Portfolio News Monitor](https://github.com/Trayast0229/portfolio-news-monitor): it scores how a news
story affects a weighted ASX portfolio with FinBERT. This Space only serves the API; the website runs on its own site
and calls it.

The files here are copied from the GitHub repository on every push to `main`. Edit them there, not here.
